# Packet Path
Open index.html in a modern browser. No build or server required. lessons.json is the editable source data; regenerate data.js as `window.LESSONS = ` followed by the JSON array after changing it. Video buttons open topic-specific YouTube searches (internet required), not verified or hosted lessons. This is a starter curriculum, not an exhaustive exam blueprint. Progress is stored locally in the browser. Export it from Profile. No backend or sync. Original abstract SVG terrain is included.

Challenge includes eight guided CLI labs. Edit labs.json and regenerate labs-data.js as window.LABS = followed by the JSON array. Commands are validated in sequence; this is not a full IOS emulator. Lab completion is saved locally.
